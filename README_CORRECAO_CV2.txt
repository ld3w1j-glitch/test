CORRECAO DO ERRO: ModuleNotFoundError: No module named 'cv2'

Esse erro significa que o OpenCV nao foi instalado no Python que esta executando o projeto.

Forma mais facil:
1. Clique duas vezes em CORRIGIR_ERRO_CV2.bat
2. Depois clique em iniciar_http.bat

Importante:
- Execute o projeto sempre pelos arquivos .bat desta pasta.
- Nao execute diretamente pelo botao Run do VS Code se ele estiver usando outro Python.
- O app foi preparado para Python 3.12.
